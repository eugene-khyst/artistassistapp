ArtistAssistApp - Third-party notices
=====================================

ArtistAssistApp is licensed under the GNU Affero General Public License v3.0.

The machine-learning models the application downloads and runs are separate
works, each under its own license. They are not part of the ArtistAssistApp
source code. This file lists them and reproduces their licenses.

The models are served split into chunks. Each entry below says where its ONNX
file comes from: an export ArtistAssistApp made itself, a file published by
the project, or a third-party conversion. The model weights were not changed
beyond what the entry describes.


Background removal
------------------

U-2-Net - models u2net, u2netp, silueta
Apache License 2.0
https://github.com/xuebinqin/U-2-Net
silueta is a size-reduced U-2-Net derivative published at
https://github.com/xuebinqin/U-2-Net/issues/295

BiRefNet - model birefnet-general-lite
Copyright (c) 2024 ZhengPeng
MIT License
https://github.com/ZhengPeng7/BiRefNet
Source checkpoint: BiRefNet-general-bb_swin_v1_tiny-epoch_232.pth
https://github.com/ZhengPeng7/BiRefNet/releases/tag/v1
ArtistAssistApp exported the checkpoint with a fixed 512 x 512 input and an
embedded sigmoid output.


Inpainting
----------

LaMa - model inpainting_lama_2025jan
Apache License 2.0
https://github.com/advimman/lama
Source checkpoint: big-lama
https://huggingface.co/smartywu/big-lama
Carve exported that checkpoint to ONNX with a fixed 512 x 512 input, and
OpenCV published the quantized ONNX file used here. Both redistributions are
also under the Apache License 2.0.
https://huggingface.co/Carve/LaMa-ONNX
https://huggingface.co/opencv/inpainting_lama


Colorization
------------

DDColor - model ddcolor-artistic-int8
Apache License 2.0
https://github.com/piddnad/DDColor
Source checkpoint: ddcolor_artistic.pth
https://huggingface.co/piddnad/DDColor-models/blob/8c3ddc6d98edc4aad9adc978e44d4fc428e2113d/ddcolor_artistic.pth
ArtistAssistApp exported the checkpoint to ONNX with a fixed 512 x 512 input
using DDColor source revision 2adb63f2656ac41cbdf7b894cddd94121a3faf13, then
quantized the MatMul and Gemm weights to int8 with ONNX Runtime dynamic
quantization, leaving the convolutions in FP32.

DDColor - model ddcolor-tiny-int8
Apache License 2.0
https://github.com/piddnad/DDColor
Source checkpoint: ddcolor_paper_tiny.pth
https://huggingface.co/piddnad/DDColor-models/blob/8c3ddc6d98edc4aad9adc978e44d4fc428e2113d/ddcolor_paper_tiny.pth
ArtistAssistApp exported the checkpoint to ONNX with a fixed 512 x 512 input
using DDColor source revision 2adb63f2656ac41cbdf7b894cddd94121a3faf13, then
quantized the MatMul and Gemm weights to int8 with ONNX Runtime dynamic
quantization, leaving the convolutions in FP32.

DexiNed - model dexined
Copyright (c) 2019 Xavier Soria Poma
MIT License
https://github.com/xavysp/DexiNed
Source checkpoint: checkpoints/BIPED/10/10_model.pth, linked from that

ArtistAssistApp exported the checkpoint with dynamic input sizes, and embedded
the sigmoid and the per-image normalization of its fused output.

Informative Drawings - model informative-drawings

TEED - model teed
Copyright (c) 2022 Xavier Soria Poma

Painting
--------

MambaPainter - model mamba-painter
Copyright (c) 2024 Tomoya Sawada
MIT License
https://github.com/STomoya/MambaPainter
Source checkpoint: last-model.pt
https://huggingface.co/STomoya/MambaPainter
ArtistAssistApp exported the stroke predictor with a fixed 128 x 128 RGB input
and 100 ordered strokes per patch. The export replaces custom GPU kernels with
portable operations, rewrites some operations to run faster, and preserves the
checkpoint weights.

VMamba, the image encoder architecture used by that model
Copyright (c) 2024 MzeroMiko
MIT License
https://github.com/MzeroMiko/VMamba

The portable Mamba2 implementation adapts code from state-spaces/mamba v2.2.2.
Copyright (c) 2024 Tri Dao and Albert Gu
Apache License 2.0
https://github.com/state-spaces/mamba/tree/v2.2.2

The application's WebGL brush renderer adapts MambaPainter's MIT renderer.

Apache License 2.0

FastViT, the backbone architecture used by that model
Copyright (C) 2023 Apple Inc. All Rights Reserved.
https://github.com/apple/ml-fastvit


Restoration
-----------

NAFNet - models nafnet-sidd-width32, nafnet-gopro-width64 and nafnet-reds-width64
Copyright (c) 2022 megvii-model
MIT License
https://github.com/megvii-research/NAFNet
Source checkpoints: NAFNet-SIDD-width32.pth, NAFNet-GoPro-width64.pth and
NAFNet-REDS-width64.pth
https://drive.google.com/file/d/1lsByk21Xw-6aW7epCwOQxvm6HYCQZPHZ/view
https://drive.google.com/file/d/1S0PVRbyTakYY9a82kujgZLbMihfNBLfC/view
https://drive.google.com/file/d/14D4V4raNYIOhETfcuuLI3bGLB-OYIv6X/view
ArtistAssistApp exported all three checkpoints with dynamic input sizes, removing the
input size check and the matching output crop from the forward pass. The
application resizes every input to a multiple of 16 instead.

The model is built on BasicSR.
Apache License 2.0
https://github.com/XPixelGroup/BasicSR


Style transfer
--------------

CAST - model cast
Apache License 2.0
https://github.com/zyxElsa/CAST_pytorch
Source checkpoint: CAST_model (latest_net_AE.pth and latest_net_Dec_B.pth)
https://github.com/zyxElsa/CAST_pytorch#test
ArtistAssistApp exported the encoder and the decoder as one model with dynamic
input sizes.

That model embeds a VGG-19 encoder. The VGG models are the work of the Visual
Geometry Group, University of Oxford, released under the Creative Commons
Attribution 4.0 International License (CC BY 4.0).
https://www.robots.ox.ac.uk/~vgg/research/very_deep/
https://creativecommons.org/licenses/by/4.0/

The style images shipped with the application are photographs of paintings
obtained from Wikimedia Commons, either in the public domain or released under
CC0.
https://commons.wikimedia.org


Upscale
-------

Real-ESRGAN - model real-esrgan-general-x4v3.onnx
Copyright (c) 2021, Xintao Wang
BSD 3-Clause License
https://github.com/xinntao/Real-ESRGAN
Source checkpoints: realesr-general-x4v3.pth and realesr-general-wdn-x4v3.pth
https://github.com/xinntao/Real-ESRGAN/releases/tag/v0.2.5.0
ArtistAssistApp blended the two checkpoints by deep network interpolation with
equal weights and exported the blend with dynamic input sizes.

The model uses the SRVGGNetCompact architecture from BasicSR.
Apache License 2.0
https://github.com/XPixelGroup/BasicSR
